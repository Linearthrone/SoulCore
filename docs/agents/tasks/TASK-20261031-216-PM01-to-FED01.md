# TASK-216 — Her-screen pointer dies before the guest

[Task] Stop the Her-screen pointer from throwing before `PutMouseEventAbsolute`, so a move or click on the embedded VM can change the guest picture.

[Reference Docs] `Agents/FED-01.md`. Live evidence: `%LocalAppData%\HouseVictoria\presence-startup.log` from 2026-10-31 03:14 through 03:19.

## Problem

Victoria's status and chat can say she is opening a page, clicking, or navigating, while the embedded VM picture does not change.

Live log, every sample in that window:

```text
her-screen click map surface=1131x903 pt=… guest=1131x903 guest0=… abs=… display=fallback
her-screen click buttons=0 cursor=held COM error: 'System.ValueTuple<int,int>' does not contain a definition for 'Value'
```

The map line is written inside `MapSurfaceToGuest`. The error line is `FormatClickFailedBeforeInjectLine`. `PutMouseEventAbsolute` is never called. `deliveryLogged` stays false. The guest framebuffer is not touched.

## Root cause

`DeliverSurfacePointer` and `DeliverSurfaceWheel` call `MapSurfaceToGuest(session, …)` where `session` is `dynamic` (`House/House.ChatDesktop/Services/VictoriaVmPointer.cs` around lines 329 and 374).

A call with a `dynamic` argument is dynamically bound, so `mapped` is `dynamic`. The method returns `(int X, int Y)?`. The binder surfaces that as `ValueTuple<int,int>`. The next expression, `mapped.Value.X` / `mapped.Value.Y` (lines 341 and 382), throws `RuntimeBinderException` because a value tuple has no `.Value`. The catch logs it as a COM error. Inject never runs.

Same defect on the wheel path.

`display=fallback` on those lines means `TryReadDisplaySize` returned null, so the slot size (1131×903) was used as the framebuffer. That is a follow-up aim risk. Do not rewrite coordinate math in this ticket. After inject works, one real click must be checked against the live guest. If the hit is in the wrong place, say so in the report and stop.

## Solution

Keep `dynamic` inside the VirtualBox session, and make the mapping result a normal `(int, int)?` at the call site.

1. Change `MapSurfaceToGuest` so its parameters are not `dynamic`. Read the display size in a helper that does not leak `dynamic` to the caller. Pass `int?` width and height into the mapper.
2. At both call sites, the variable that is `.Value`'d must be a statically typed `(int X, int Y)?`.
3. Do not catch this binder failure and label it a COM error. If mapping throws, the log should say the mapping result was not a nullable point.

## Do not touch

- Host `VboxConsoleMouse` / `browser_navigate` success rules (BED). This ticket is the Presence inject path only.
- Guest framebuffer scaling, Absolute `+1`, wheel `dz`, cursor parking.
- `SoulCore/.env` and any secret.
