# TASK-20261031-216 — FED-01 report

A Her-screen move or click was dying after the map line and before `PutMouseEventAbsolute`. `MapSurfaceToGuest` was called with the dynamic VirtualBox session, so the nullable point came back as `ValueTuple<int,int>` and `.Value` threw `RuntimeBinderException`. That catch wrote the failure as a COM error. The guest framebuffer was never touched.

`dynamic` now stays inside `ReadSessionDisplaySize`. Call sites box the session to `object`, pass `int?` display width and height into `MapSurfaceToGuest`, and read `.Value` on a statically typed `(int X, int Y)?`. The same path is used for the wheel. If that binder failure still escapes, the log says the mapping result was not a nullable point and does not say COM error.

Coordinate math, wheel `dz`, Host `VboxConsoleMouse`, `browser_navigate`, and `SoulCore/.env` were not changed. No live click was sent, so this report does not claim the guest picture moved. `display=fallback` is unchanged and was not retuned.

Tester note uses LinearThrone.
